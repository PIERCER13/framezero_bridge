# Changelog

## 1.6.0
- Current release.
- One API (`framezero`) for ESX, QBCore, Qbox, vRP, vRPex, Creative, tnet, ndcore, oxcore and standalone.
- Auto-detection of inventory, garages/keys, notifications, target, progress, phone, dispatch, doorlock and anticheat.
- Shared stashes, society accounts, Discord logging with rate-limit protection, 30+ minigame adapters.
- `custom/` folder for overrides that updates never overwrite.
